### Summary

The database layer is sound: row-level security with NULLIF, composite organisation keys, the pinned definer function, role grants, one-transaction approval with item-then-proposal locking, and idempotency scoped by organisation all match the design and are tested. The deploy workflow can run untrusted fork code with the live deployment secrets, which blocks approval. The raw database handle given to routes, the missing job-queue maintenance and the C3 interface differences also need changes first.
