### Summary

The catalogue is structurally sound and all four confirmed decisions are reflected. The main gaps are two places where the append-only and sole-writer guarantees have unwritten exceptions (confirmations, unowning), and an undeclared path for moving waiting proposals when a user is deactivated. Both should be settled in the ADRs before Functional Design, but neither blocks implementation of the component boundaries.
